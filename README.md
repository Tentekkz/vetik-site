# Сайт Татьяны Ветик

Сайт наставника по Kaspi в концепции «Учебник»: тетрадь в клетку, красная ручка учителя, параграфы.

## Страницы

- **Главная** — кто она, три способа выйти в закрытую категорию, журнал успеваемости.
- **Атлас категорий** — 92 ограниченные подкатегории из прайса с поиском, фильтром и сортировкой; заявка уходит в WhatsApp с готовым текстом.
- **Курс PROдоступ** — программа из 9 глав, для кого курс, формат.
- **Калькулятор** — чистая прибыль, маржа и окупаемость открытия категории.
- **Обо мне** — личное дело, хронология, принципы работы.
- **Кейсы** — реальные результаты учеников и клиентов.

## Как устроено

Один файл `index.html` без сборки и зависимостей. Шрифты: Literata, Golos Text и Bad Script (Google Fonts).
Страницы переключаются по адресу: `#atlas`, `#course`, `#calc`, `#about`, `#cases`.

## Что ещё нужно

- Фото Татьяны вместо заглушек (кнопка «Показать заметки для правки» внизу страницы подсвечивает все места).
- Стоимость курса и актуальные даты потока.
- Оригинальные скриншоты отзывов и кабинетов.
